# HL7: ACK/NACK

**Not implemented.** See [README.md](README.md). Eir's own `eir.lab.v1`
protocol has its own acknowledgement shape (`status: accepted | rejected`
with a restricted `reasonCode` enum — see
[../integrations/README.md](../integrations/README.md) and
[docs/INTEGRATIONS.md](../../INTEGRATIONS.md) "Wire Contract"); it is not an
HL7 ACK/NACK message and must not be described as one.
